# Comfy Manager 使用文档

当前稳定版本：`v2.2.1`

## 项目简介

Comfy Manager（灵动图库）是围绕 **ComfyUI output** 使用场景构建的桌面管理工具，重点解决这些高频问题：

- output 目录越用越大，回看历史成本高
- PNG 元数据、Prompt、模型、LoRA 信息分散
- 目录、收藏、标签、笔记缺少统一管理入口
- 提示词复用与看图筛图之间缺少顺手的闭环

## v2.2.1 功能概览

### 核心能力

- 绑定任意 ComfyUI `output` 目录
- 默认目录 / 日期归档目录 / 自定义目录并行浏览
- 日期产出工作台
- 模型 / LoRA / 标签 / 笔记 / 收藏筛选
- PNG 元数据、Workflow、Prompt 查看与复制
- 自动规则引擎
- 提示词助手

## 常用入口说明

### 工作台总览

用于快速看到：

- 最近作品
- 今日新增
- 图片总数
- 存储占用
- 常用入口

### 日期产出工作台

适合按日期回看近期创作：

- 今天 / 昨天 / 最近 7 天 / 本月
- 自定义日期范围
- 叠加模型和 LoRA 条件
- 点击活跃日期快速跳回图库

### 图库页

适合细看、筛图和批量整理：

- 搜索文件名、Prompt、模型、LoRA
- 收藏、标签、笔记联动
- 排序与分页
- Lightbox 详情查看

### 提示词助手

适合做本地 Prompt 工作流：

- 搜索词库
- 分类筛选
- 分页浏览
- 快速加入正向 / 反向 Prompt
- 保存模板和常用组合
