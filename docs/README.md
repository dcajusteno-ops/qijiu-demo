# Comfy Manager 使用文档

当前稳定版本：`v3.0.1`

这份文档面向最终使用者，重点回答三件事：

1. 这个软件是干什么的
2. 第一次进入应该怎么设置
3. 常见工作流应该怎么走

---

## 1. 软件定位

Comfy Manager 是一个围绕 **ComfyUI output 目录** 的桌面整理器。

它重点解决的不是“怎么生成图片”，而是生成之后更麻烦的那部分：

- output 越堆越大，历史作品回看困难
- 模型、LoRA、Prompt、标签、笔记分散在不同地方
- 想按日期、主题、模型或收藏快速回看时效率低
- 想做长期整理时，目录、缓存、回收站、提示词模板缺少统一入口

如果你平时已经有大量 ComfyUI 图片，这个软件的目标就是让你：

- 更快找到想看的图
- 更快整理 output
- 更稳定复用 Prompt 和模板
- 更可控地维护自己的图像资料库

---

## 2. 首次使用

### 2.1 运行方式

你可以用两种方式启动：

- 安装版：运行 `ComfyManager-amd64-installer.exe`
- 便携版：直接运行 `desktop-app.exe`

### 2.2 第一次必须做的事：绑定 output

首次进入时，软件会要求你选择 **ComfyUI 的真实 output 文件夹**。

正确示例：

```text
D:\AiImg\ComfyUI-aki-v3\ComfyUI\output
```

不要选择：

- 软件 exe 所在目录
- `output` 下面的子目录
- 其他不相关目录

绑定完成后，软件会自动切换图片来源，并根据这个目录计算：

- 当前 output 目录
- 当前根目录
- 默认目录树
- 日期归档目录
- 自定义目录可选范围

### 2.3 如果 output 位置后来变了怎么办

可以在软件里重新绑定，不需要重装。

入口通常有两处：

- 初次进入时的绑定弹窗
- 工具菜单里的 output 重新绑定入口

## 3. 主界面怎么理解

### 3.1 工作台总览

这是打开软件后的主入口，适合快速确认当前状态。

这里会看到：

- 最新作品
- 今日新增
- 图片总数
- 当前存储占用
- 最近更新缩略流

适合在开始工作前快速看一眼“最近发生了什么”。

### 3.2 日期产出

适合按时间维度回看最近创作。

常见用法：

- 今天
- 昨天
- 最近 7 天
- 本月
- 自定义日期范围

如果你最近连续做一个主题，想快速看“这几天到底出了哪些图”，这里通常是最顺手的入口。

### 3.3 默认目录 / 自定义目录

这里是更细致的图库视图，适合做筛图和整理。

你可以：

- 看某个目录下的全部图片
- 按搜索词筛选
- 按模型 / LoRA / 标签 / 笔记进一步缩小范围
- 进入大图查看和批量模式

### 3.4 收藏夹

用来保存长期想保留、想二次整理、或想后续复用的内容。

收藏不只是“打一个心”，还可以继续配合：

- 收藏分组
- 标签
- 笔记

把收藏从“临时标记”变成可长期维护的筛选入口。

### 3.5 数据视界

用来看总量和趋势，而不是逐张看图。

适合：

- 看最新产出趋势
- 看目录总体规模
- 看当前存储压力
- 做大图库维护前的判断

### 3.6 提示词助手

这是本地 Prompt 工作流入口。

可以做的事：

- 搜索词库
- 按分类筛选
- 分页浏览
- 拼装正向 / 反向 Prompt
- 管理自定义提示词词条
- 管理模板

如果你经常重复写相似 Prompt，这里会很有用。

## 4. 常见工作流

### 4.1 回看最近几天的作品

1. 打开“日期产出”
2. 选择“今天”“昨天”或“最近 7 天”
3. 如果还想继续缩小范围，再叠加模型或 LoRA
4. 找到目标图后，可以直接进入大图查看或跳回图库继续细筛

### 4.2 按模型或 LoRA 查找作品

1. 进入任意图库页
2. 打开筛选区
3. 选择模型或 LoRA
4. 如结果为空，优先检查是否还有搜索词、日期或标签筛选残留

建议习惯性使用“清空全部筛选”，避免误以为图片丢了。

### 4.3 给图片加标签和笔记

1. 进入图库或大图查看
2. 给当前图片添加标签
3. 需要长期备注时补上笔记

适合记录：

- 题材
- 角色
- 风格
- 可复用提示词思路
- 后期想返工的说明

### 4.4 使用收藏夹做二次筛选

1. 先把值得保留的图加入收藏
2. 再按收藏分组整理
3. 后续用收藏夹页面继续筛图和复查

这样可以把“全量 output” 和 “值得保留的结果” 分层管理。

### 4.5 使用提示词助手复用 Prompt

1. 打开提示词助手
2. 搜索目标词条
3. 加入正向或反向区域
4. 保存成模板，供后续重复使用

适合把“常用构图、常用质量词、常用角色描述”固化下来。

### 4.6 使用自动规则减少手工整理

自动规则适合这些场景：

- 某个模型的图自动打标签
- 某类 Prompt 自动归类到指定目录
- 某类作品自动加入收藏分组

建议从简单规则开始，先少量验证，再逐步增强。

### 4.7 大图库维护

当图片很多时，建议定期做三件事：

1. 清理空文件夹
2. 清理失效标签或收藏引用
3. 清理预览 / 缩略图缓存

这部分可以在设置中心或目录健康入口里完成。

## 5. 目录与数据说明

### 5.1 软件会维护哪些数据

常见运行数据放在：

- `data/favorites.json`
- `data/tags.json`
- `data/image-tags.json`
- `data/image-notes.json`
- `data/custom-roots.json`
- `data/settings.json`
- `data/auto-rules.json`
- `data/trash-metadata.json`
- `data/image-meta-cache.json`
- `data/prompt-library/`

### 5.2 删除图片后会发生什么

默认不是直接彻底删掉，而是先进入回收站。

你可以：

- 恢复
- 批量恢复
- 清空
- 让软件按保留天数自动清理

这比直接删文件更安全。

## 6. 快捷操作建议

常用操作可以优先记住这些：

- `Esc`：关闭大图或退出当前选择状态
- `Delete`：删除当前选中图片
- 方向键：在大图中切换上一张 / 下一张
- `Ctrl + 0`：在大图中重置缩放

软件还提供全局快捷键设置，可在设置中心里调整。

## 7. 常见问题

### 7.1 侧边栏明明有数量，为什么主区域没图

最常见原因不是图片没了，而是还有筛选残留：

- 搜索词
- 日期范围
- 模型
- LoRA
- 标签
- 收藏条件

先尝试清空全部筛选。

### 7.2 为什么软件要我手动选 output

因为从新版本开始，软件不再默认猜测 exe 的相对路径。  
这样可以适配：

- 便携使用
- 任意安装位置
- 多套 ComfyUI 目录

也能避免因为路径猜错导致扫描错误目录。

### 7.3 为什么会看到“性能模式”提示

当当前图库很大时，软件会自动倾向使用更轻的加载策略，比如：

- 轻量分页
- 缩略图 / 预览图变体
- 更保守的刷新方式

这样做是为了在大图库下保持可用性。

### 7.4 提示词助手的数据从哪里来

运行时主要读取项目里的：

```text
data/prompt-library/
```

它是本地可维护的数据目录，不依赖远程服务。

### 7.5 output 改位置后软件异常怎么办

优先重新绑定 output，再刷新图库。  
如果之前缓存很多，也可以再清一次预览缓存。

---

## 8. 推荐使用顺序

如果你是第一次长期用这套工具，建议顺序如下：

1. 先绑定 output
2. 在工作台总览确认数据正常
3. 用日期产出回看最近作品
4. 用默认目录和自定义目录做长期筛图
5. 把满意结果放进收藏夹并加标签
6. 把常用 Prompt 固化到模板
7. 最后再尝试自动规则
