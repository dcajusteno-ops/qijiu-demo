# Comfy Manager

Comfy Manager（灵动图库）是一套面向 **ComfyUI output 目录** 的桌面创作管理工具，基于 **Wails v2 + Go + Vue 3** 构建。

它不只是看图器，而是围绕 ComfyUI 的真实工作流，把这些事情串起来：

- 浏览和回看历史出图
- 按日期、模型、LoRA、标签、收藏快速筛选
- 查看 PNG 元数据、Prompt、Workflow
- 管理自定义目录、收藏夹、标签和笔记
- 用提示词助手做本地 Prompt 复用

当前稳定版本：`v2.2.0`

## v2.2.0 重点更新

- 新增大型图库性能模式
- 新增目录健康中心
- 列表页接入缩略图 / 预览图变体，减轻大图加载压力
- 日期工作台、工作台总览、统计页的数据口径进一步统一
- 分页交互升级为悬浮式分页，并支持手动输入页码
- 自定义目录管理增强：
  - 支持置顶 / 取消置顶
  - 侧边栏固定按置顶状态排序
  - 新增状态徽标与排序禁用反馈
  - 编辑区改为内部滚动，避免撑乱整体布局
- 修复性能模式下的几个关键回归：
  - 分页请求乱序覆盖
  - 标准 / 性能模式切换后数据不完整
  - 删除后分页列表不同步
- 更新 Windows 安装程序并同步安装版文档

## 核心能力

- 绑定任意 ComfyUI `output` 目录
- 默认目录、日期归档目录、自定义目录并行浏览
- 日期产出工作台
- 模型 / LoRA / 标签 / 笔记 / 收藏筛选
- PNG 元数据查看、复制与工作流读取
- 收藏夹与收藏分组
- 标签、笔记、批量模式
- 自动规则引擎
- 提示词助手与本地 Prompt 词库
- 设置中心与工具菜单
